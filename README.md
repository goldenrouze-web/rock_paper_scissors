# Игра Камень-Ножницы-Бумага

## Описание
Мини-игра на Python, где игрок соревнуется с компьютером.
Поддерживает русский язык и подсчет очков.

## Как играть
1. Запусти игру командой:
python3 game.py
2. Вводи:
- камень
- бумага
- ножницы
3. Для выхода введи:
- выход
- 0

## Функциональность
- Подсчет очков игрока и компьютера
- История ходов
- Главное меню

## Требования
- Python 3.x
